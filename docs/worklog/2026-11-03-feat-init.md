## Request

Bring the 123 Factory company website and its project setup into this repository, which so far holds only an initial commit. Before committing, review the branch for files that should not be committed, close the gaps in `.gitignore`, leave out the `apple-design` skill for now, and write this worklog. The review also asked to clean up `package.json`, remove camera and editing metadata from two photos, and remove the commercial fonts and every code reference to them before the first commit, because the repository will become public.

## Changes

- **Site source**: adds the React, React Router, and Vite app (`src/`, `index.html`, `vite.config.js`, `package.json`, `package-lock.json`) and its static assets (`public/`). The Vite config copies `index.html` to `404.html` at build time so GitHub Pages can serve client-side routes.
- **CI and guardrails** (protected paths): adds the GitHub Pages deployment and PR check workflows (`.github/workflows/`), the secret and personal-data scan rules (`.gitleaks.toml`), and the agent instructions (`AGENTS.md`). A trusted maintainer must author the PR, or the `protected-paths` check fails.
- **Documentation**: expands `README.md` and adds the Git workflow docs, the worklog template, and this worklog (`docs/git-workflow/`, `docs/worklog/`).
- **`.gitignore`**: ignores dependencies, build output, logs, and `/scratch/`, which holds the original images. The review added `.env`, `.env.*`, `.idea/`, and `.vscode/`, while keeping `.env.example` committable, so that `git add -A` cannot pick up environment files or editor settings.
- **`package.json`**: removes `lucide-react`, which `src/` does not use, and `@types/react` and `@types/react-dom`, since the project has no TypeScript files. Also removes the `lint` script, which could not run because ESLint is not installed. Adding ESLint was not part of this request.
- **Image metadata**: removes EXIF, XMP, and Photoshop segments from `public/startups/startups-main-hero.jpg` and `startups-sprint.jpg` without re-encoding. The ICC color profiles stay. The 300 DPI value is removed with the metadata, which does not affect display on the web.
- **Fonts**: excludes the two commercial font families from the repository, along with their `@font-face` rules and name references, because one foundry's terms prohibit public repositories and no proof of purchase was found. `--font-editorial` and `--font-mono-editorial` now point to Inter and Space Grotesk. Both are open-source and already loaded from Google Fonts. The feed page already overrode these variables with the same fonts, and no other code uses them, so the commercial fonts were never rendered. A closer match to the commercial design, such as Hanken Grotesk, was not adopted because it would change the look of the live pages.

### Open items for the reviewer

- Font stacks still name fonts installed on visitors' devices, such as SF Pro, Helvetica Neue, and Segoe UI. No font files are distributed for them, so they were kept.
- Confirm consent to publish the team member photos in `public/`. Files stay in Git history even if they are deleted later.
- `public/offices/berlin.jpg` and `seoul.jpg` contain small EXIF and Photoshop segments, which were not requested for removal.
- `npm audit` reports 4 vulnerabilities (3 moderate, 1 high). They were not addressed in this PR.
